### Agent 与工具

**Anthropic 找外部律所制定 AI agent「议价规范」**
- 要点：据 FT（北京时间 10 月 19 日上午）报道，Anthropic 正向律所咨询如何为代表用户谈判的 AI agent 制定公平议价规范：何时应回头请示用户、对对手 agent 应保持多高的警惕、用户签署数字授权文件确认 agent 权限边界。背景是内部实验 Project Deal：员工用 Claude agent 买卖二手物品成交 186 笔约 4000 美元；强模型平均卖出价高 2.68 美元、买入价低 2.45 美元，用弱模型的用户大多没意识到吃了亏。

- 来源：[Financial Times（经 PYMNTS 转述）](https://www.pymnts.com/news/artificial-intelligence/2026/anthropic-turns-to-lawyers-to-teach-ai-agents-to-negotiate/) · 交叉来源：The Decoder

**Proof 联手 Circle 演示：agent 用 x401 出示身份凭证、用 USDC 经 x402 付款**
- 要点：10 月 19 日两家公司在 Money20/20 上演示 AI agent 完成一次身份门控购买：agent 经 Proof 的开放身份协议 x401 出示经验证的身份凭证（利用 HTTP 401 "Unauthorized" 响应让网站告诉 agent 需要何种身份证明），再用 Circle Agent Wallet 经开放支付协议 x402 以 USDC 付款（利用 HTTP 402 "Payment Required" 响应）。商户用 Proof 公开的公钥校验签名后订单完成。
- 为什么重要：直接解决 agent 商务的最大障碍——商家分不清「谁派来的 agent、有没有用户授权」，是 agent 经济从被封堵走向被接纳的关键基础设施拼图。
