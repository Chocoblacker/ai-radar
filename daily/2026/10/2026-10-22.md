# 📡 AI 雷达 · 2026-10-22（周四）

> 30 秒速览：AI 发现的 PHP 史上最严重漏洞之一，引发全球网站连夜下线打补丁；热门 LLM 网关库 LiteLLM 今年内第二次供应链被攻破，任何用过恶意版本的机器都要假定密钥泄露；Meta Q3 广告收入大涨 26%、盘后涨超 4%，暂时缓解了市场对 AI 资本开支的质疑。

## 一、今日三件事

1. **PHP2Shell：AI 发现的 PHP 史上最严重漏洞，全球网站连夜打补丁。** PHP 官方紧急修补两个潜伏多年的严重漏洞，影响近 20 年发布的所有版本（PHP 驱动约 70% 的网站）。漏洞由 AI 在资助审计中发现（Calif 用 GPT-5.6 Sol、Wiz 用 Gemini 4 Argon 独立确认），NSA 要求机构立即打补丁或直接下线，多国政府门户预防性关闭。专家警告补丁公开后 AI 可轻易逆向漏洞，"抢跑式利用"竞赛已经开始。
2. **LiteLLM 供应链再被攻破，恶意版本窃取云凭证。** 热门 LLM 网关库 LiteLLM 的发布流水线被攻破，恶意版本 v1.107.0 被推送到 PyPI 和 Docker 约 2 小时——恶意代码借 `cook.pth` 机制在 Python 启动时自动执行，无需 import 即可窃取云凭证、私钥和 AI 工具认证文件。攻击者用被盗的工程师 GitHub CLI OAuth token 走合法流水线发布。这是 LiteLLM 在 2026 年内第二次供应链被攻破。
3. **Meta Q3 广告 +26% 超预期，盘后涨超 4%。** Meta Q3 营收 646 亿美元（+26%），广告收入 630.6 亿美元、展示量和单价双涨，Q4 指引中点超市场共识；扎克伯格在财报中宣布发布 "Muse" 和 "Muse Wonder" 首个前沿模型，Reality Labs 亏损路径继续收窄。同日 Google Cloud 宣布 OpenAI 的 GPT-6 Astra / GPT-6.1 Sol / GPT-6 Luna 以 private preview 进驻 Model Garden，成为唯一同时提供 Gemini、Claude、GPT 的主流云厂商。

## 二、AI 主线

### 模型与产品

**Recursive 发布 Flint：首个宣称"AI 自动化科研系统"建成的开源代码模型**
- 要点：You.com 创始人 Richard Socher 旗下初创 Recursive 发布面向代码 Agent 的 MoE 模型 Flint，总参数 39.8B、每 token 仅激活 2.5B，Apache 2.0 协议上架 Hugging Face，可免费商用。公司称 SWE-bench Verified 得分 74.2%（公司自报，领先 50B 以下 MoE），MacBook Pro（M4 Pro）上生成速度超 125 tokens/s，Wired 记者已在 48GB 内存 Mac 上实测可用。
- 为什么重要：首个把"AI 造模型"当卖点的公开权重发布——Recursive 称 Eureka Machine 参与了架构、量化、内核和训练全流程，是 recursive self-improvement（RSI）叙事的第一次公开落地。
- 来源：[MarkTechPost](https://www.marktechpost.com/2026/10/21/recursive-flint-local-coding-model/) · 交叉来源：Wired 实测、Richard Socher 官方 X 帖

**NVIDIA 发布 Agent Knowledge Foundation，开源 Kumo 关系型数据基础模型**
- 要点：NVIDIA 宣布面向企业 Agent 的开放模型与工具库 Agent Knowledge Foundation，核心是 Kumo 模型家族（Tabular / Relational / Time Series / Forecast + Nemotron Retriever）。旗舰 Kumo Relational 是预训练的关系型数据基础模型：聚合至多 10,000 个历史样本做上下文，单次前向完成预测，无需任务训练或特征工程；权重以 OpenMDW 1.1 协议上架 Hugging Face，代码 Apache 2.0，另有 NIM 微服务。

### AI 安全事件

**LiteLLM v1.107.0 供应链攻击：恶意版本窃取云凭证并植入远控后门**
- 要点：10 月 21 日凌晨，约 2,300 万周下载量的热门 LLM 网关库 LiteLLM 发布流水线被攻破，恶意版本 v1.107.0 被推送到 PyPI 和 Docker 镜像仓库，存在约 2 小时后被下架。恶意代码通过 `cook.pth` 机制在 Python 启动时自动执行（无需 import 包），包含凭证窃取器和远程访问木马（RAT），窃取云凭证、私钥、浏览器数据和 AI 工具认证文件，外发到仿冒域名 litellm.dev。LiteLLM 官方确认：攻击者用被盗的三名工程师 GitHub CLI OAuth token 触发并批准了对恶意 fork（`Berri-AI/litellm`，与真叉仓库 `BerriAI/litellm` 差一连字符）的构建，借合法流水线发布。企业私有版本未受影响，最新安全版本为 v1.106.2。
- 为什么重要：直接命中 AI 开发基础设施的供应链攻击——跑着这个版本的任何机器都应假定密钥已泄露并全部轮换；这是 LiteLLM 在 2026 年内第二次供应链被攻破，连发布流水线本身也需要防护。
- 来源：[LiteLLM 官方安全事件页](https://docs.litellm.ai/blog/security-incident-oct-21-2026) · 交叉来源：The Register、Datadog Security Labs、The Hacker News
- 可信度：✅已证实

**PHP2Shell：AI 发现的 PHP 史上最严重漏洞之一，全球网站被迫下线打补丁**
- 要点：PHP 官方 10 月 21 日紧急发布补丁，修复两个已潜伏多年的严重漏洞（被命名为 PHP2Shell），影响近 20 年发布的所有 PHP 版本，PHP 驱动着约 70% 的网站（WordPress、Drupal、Joomla、Magento 等）。漏洞由 AI 发现：安全公司 Calif 用 OpenAI 的 GPT-5.6 Sol 在 OpenAI 资助的代码审计中于 8 月发现，Wiz 用 Google Gemini 4 Argon 等模型数周后独立发现。美国 NSA 要求机构立即打补丁或直接下线，欧洲多国（荷兰政府门户、鹿特丹港、德国 ITZBund 等）预防性关闭网站。
- 为什么重要：AI 既是发现者也是"放大器"：2026 年漏洞披露量预计翻倍，而 AI 让补丁逆向和利用开发都变快，攻防双方都在被 AI 重塑；对运维是即时行动项——只要跑 PHP，必须立即升级。
- 来源：[Reuters（经 Channel News Asia）](https://www.channelnewsasia.com/world/websites-go-dark-worldwide-ai-exposes-critical-security-flaws-6478206) · 交叉来源：WSJ、美国 NSA 官方声明、PHP 基金会官方博客
- 可信度：✅已证实

## 五、信号与趋势

1. **AI 正在把安全攻防的节奏同时按快两档。** PHP2Shell 的两个漏洞都是 AI 发现的（Calif 用 GPT-5.6 Sol、Wiz 用 Gemini 4 Argon 独立确认），但补丁公开后 AI 又让漏洞逆向和利用开发变快，"抢跑式利用"的窗口被压缩；另一边 LiteLLM 供应链攻击显示，连 AI 开发基础设施的发布流水线本身都成了猎物。依据 A13、A14。防御方的补丁速度现在要和 AI 逆向速度赛跑，这对所有运维团队都是刚性压力。
2. **内存荒正在从"涨价"演化为"产业链变形"。** 三星/SK 在美方许可框架下升级在华 NAND 产能、美光 CTO 公开否定 4F² 路线押注 3D DRAM、手机厂商甚至开始回收二手 DRAM 装进新机——短缺已经传导到消费电子。美光自称供应紧张至少再持续两年，存储价格的高位恐怕是新常态。依据 A10、A11、A12。
3. **常开式主动 Agent 成了三大实验室标配。** Claude Duet 补上了 Anthropic 的"主动找你"拼图（继 Meta Muse、OpenAI Dots 之后）；企业端 ServiceNow Arc 则把 Agent 治理下沉到 NVIDIA BlueField 硬件层——说明企业 Agent 真正的战场不在模型能力，而在权限治理。依据 A6、A7。
