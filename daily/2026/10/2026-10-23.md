### Agent 与工具

**AAIF 一次纳新 4 个项目：Agent Skills、Open Responses、OpenEnv、OpenSandbox**
- 要点：10 月 22 日在 AGNTCon + MCPCon 北美大会上宣布，Anthropic 捐出 Agent Skills、OpenAI 捐出 Open Responses（跨厂商模型接口规范）、Hugging Face 捐出 OpenEnv（强化学习环境框架）、阿里捐出 OpenSandbox（多语言沙箱运行时）；AAIF 一年内从 3 个项目扩到 10 个。

- 可信度：✅已证实

**Trust3 AI 推出 Agent DOS 与 Claude Code 集成：企业级 Agent 治理**
- 要点：10 月 22 日宣布其 Agent DOS 治理平台接入 Claude Code，无需在开发者机器安装任何软件即可给企业安全团队提供 Claude Code 会话全量可见性；每个 Claude Code 用户被登记为有明确负责人的 AI Agent，覆盖其会话中触达的 MCP 服务器和工具。

- 来源：[Business Wire（公司官方通稿）](https://www.businesswire.com/news/home/20261022743314/en/Trust3-AI-Brings-Enterprise-Agent-Security-to-Claude-Code) · 交叉来源：Morningstar 转载

## 五、信号与趋势

1. **（分析）AI capex 从"讲故事"进入"验算"阶段。** Lam Research 指引平淡、Tesla 把 2026 年 capex 从 250 亿+砍到约 200 亿，直接触发费半 -6.72%；但 TI 和 Besi 同一天超预期——需求仍在，分歧的是"谁的订单能变成真金白银"。依据。接下来每一份设备商和云厂商财报都会被用同一把尺子量。
