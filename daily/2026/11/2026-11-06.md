**【A1】 OpenAI 发布 GPT-6 Cyber：一次运行验证 948 个 Linux 内核提权漏洞，成本 121 万美元**
- 要点：11 月 5 日发布的 GPT-6 Cyber 基于 GPT-6 Astra，仅限 Daybreak Red 计划中通过身份审核的安全客户；ExploitGym 得分 48.5%，高于 GPT-5.6 Cyber 的 32.1% 与 GPT-6 Astra 的 42.4%；越权率在 HoneyPot 评估中不到 1%（GPT-5.6 Cyber 约 5%）。同一框架的 Agent 管线一次运行审计约 280 万行内核代码，复现 1,724 个候选发现、去重后为 948 个不同漏洞且各配候选补丁，已向维护者送出数百份报告；全程 API 成本 1,213,430 美元，折合每个漏洞约 1,279 美元。
- 为什么重要：这是"能主动找漏洞、写 exploit"的模型首次产品化并定为最高风险等级，防御方与攻击方同时拿到同款工具，内核补丁节奏必须按"低权限立足点约等于 root"来排。
- 来源：[The Register](https://www.theregister.com/security/2026/11/05/openai-releases-gpt-6-cyber-and-promises-this-one-stays-within-rules-of-engagement/5307855) · 交叉来源：Unite.AI、Interesting Engineering · 🟡多方报道
