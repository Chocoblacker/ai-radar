## 二、AI 主线

### AI 安全

**【A1】 Claude Code"不再询问"致 2,539 个密钥流入公开 GitHub，Anthropic 仍无公开回应**
- 要点：安全公司 Apiiro 11 月 5 日披露，开发者在 Claude Code 权限弹窗选"Yes, and don't ask again"后，含密钥的完整命令会以明文写入项目内 .claude/settings.local.json，随代码推到公开仓库即泄露。扫描发现 1,122 份该文件含 1,379 个独立密钥，计入 git 历史与共享配置后总数达 2,539 个。根因是 Claude Code 只把该文件加入用户全局 git excludes、而非项目自身的 .gitignore，保护随仓库失效；截至 11 月 8 日 Anthropic 仍无公开回应。
- 为什么重要：这是 AI 编程助手"把密钥写进配置文件"的系统性设计问题，且常规密钥扫描对此类明文密码漏检严重——所有用 Claude Code 的开发者和运维团队都应立即自查。
- 来源：[Aviatrix](https://aviatrix.ai/threat-research-center/claude-code-dont-ask-again-settings-local-json-passwords-keys-1122-github-2026/) · 交叉来源：Apiiro 原始研究 · 🟡多方报道（数字全部来自 Apiiro 一家统计，未经第三方复核；原始报告 11 月 5 日，窗口内是 11 月 7–8 日的跟进与"仍无回应"这一新状态）
