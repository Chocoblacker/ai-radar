### 模型与产品

**【A1】 Anthropic 发布 Claude Fable 5.2 与 Mythos 5.2，定价降 20%、输出快 30%**
- 要点：11 月 9 日官方发布，Fable 与 Mythos 为同一底层模型。定价 8/40 美元每百万输入/输出 tokens，比 5.1 的 10/50 美元降 20%，输出快约 30%，另有 2.5 倍速 fast mode。FrontierCode 2.0 得 49.1%，高于 Opus 5.5（45.5%）与 GPT-6 Astra（42.8%）；1000 个 Fable 5.2 Agent 30 小时内形式化了费马大定理证明。
- 为什么重要：上市前夜最重要的一次模型发布，"降价+提速"直接压低旗舰级 Agent 任务成本；同时训练中主动把最能加速 AI 研发的能力（芯片内核优化、改进 LLM 架构）压在 Opus 5.5 水平，回应了"AI 加速自身"的争议。
- 来源：[Anthropic 官方公告](https://www.anthropic.com/claude-fable-and-mythos-5-2) · 交叉来源：Reuters、CNBC、The Verge · ✅已证实（基准分为 Anthropic 自测，未经独立复核）

**【A2】 Meta 发布 Muse Ember，定位 Agent 重复性任务的小模型，每任务约 0.14 美元**
- 要点：11 月 9 日发布并上线 Meta Model API 与 Muse Code，定价 0.10/0.50 美元每百万输入/输出 tokens（缓存 0.004 美元），上下文 100 万 tokens、最大输出 51.2 万 tokens；Artificial Analysis 指数 36 分，每任务约 0.14 美元，与 Haiku 5.5 最好成绩持平、成本约三分之一。
- 为什么重要：专为 Agent 高频重复工作设计，Muse 家族形成 Wonder 规划 + Ember 执行的分工；首个用 Muse Wonder Full 训练的模型，小模型性价比战开打。

### AI 安全

**【A3】 🔄更新 Claude Code 密钥泄露：GitGuardian 称规模远大于 Apiiro，另波及 Docker Hub**
- 要点：GitGuardian 11 月 9 日发布持续监测数据：2025 年 1 月至 11 月 7 日，公开 GitHub 上 `.claude/settings.local.json` 共含 31,088 个不同密钥、分布在 23,276 个仓库，其中 5,343 个在发现时仍有效；另有 613 个密钥（99 个有效）流入公开 Docker Hub 镜像，一个有效 Cloudflare token 出现在 559 个镜像标签中。Apiiro 的 2,539 个是当前快照，GitGuardian 是历史全量，口径不同、数字不矛盾。Anthropic 窗口内仍无新回应。
- 为什么重要：量级上修一个数量级，并新增 Docker Hub 这一删库也清不掉的泄露面；运维自查须从 GitHub 扩大到镜像仓库，泄露的密钥必须轮换、只删文件没用。
- 来源：[GitGuardian 官方博客](https://blog.gitguardian.com/claude-code-settings-local-json-secrets-docker-hub/) · 交叉来源：Cybernews、Apiiro 原始研究 · 🟡多方报道（数字全部来自 GitGuardian 一家统计，未经第三方复核）
