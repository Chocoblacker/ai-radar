### Agent 安全

**【A6】MCP 官方工具链同日密集修复：参考服务器 8 条安全公告、Inspector 补 NAT64 SSRF 绕过**
- 要点：官方 MCP 参考服务器 11 月 27 日集中发布 8 条安全公告（均无 CVE 编号）：最严重的是 GHSA-6663-fm5v-gqm5（CVSS 7.8），仓库自带的 `.git/config` 可通过 Git LFS filter 指定并执行任意程序，触发工具包括被标为只读的 `git_status`；前提是用户装有 Git LFS 且仓库 `.git` 目录由他人写入，普通 `git clone` 不足以触发。另有 `git_remote` 可泄露全局 Git 配置中的凭据（5.3）、server-memory 权限竞争（4.2）。修复版 mcp-server-git / mcp-server-fetch 2026.11.27、server-memory 2.2.2 同日发布。同日 MCP Inspector 2.17.0 修复 NAT64 形式的 SSRF 绕过（GHSA-v2gx-m79c-pvxj），恶意 MCP 服务器可借此让 Inspector 后端直连云元数据地址。
