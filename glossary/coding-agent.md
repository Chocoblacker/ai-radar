# coding agent（编码智能体）

## 是什么

能自主完成"理解需求 → 写代码 → 运行 → 修 bug"闭环的 AI Agent，不只是补全代码的 Copilot。它自己规划步骤、调用工具（终端、测试、浏览器）、根据报错反复迭代，直到任务完成。

## 为什么重要

GitHub Octoverse 2026 数据：2026 年 9 月超 40% 的 PR 首 draft 来自 coding agent（3 月仅 17%），单月 1.1 亿个 agent 启动的 PR——代码生产的主力已经从人变成 agent。

## 常见误区

- 以为它只是"更聪明的代码补全"：补全是被动响应，coding agent 是主动执行多步任务。
- 以为用了 coding agent 就不用看代码：恰恰相反，agent PR 两周内合并率 90%，瓶颈移到了"审代码"，review 能力正在成为新的稀缺技能。
