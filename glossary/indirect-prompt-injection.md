# 间接提示注入

**是什么：** 攻击者把恶意指令藏在 AI Agent 会抓取的网页、文档、邮件里。当 Agent 读取这些内容时，会误把恶意指令当成用户指令执行。可以理解为给 AI 下的"催眠术"——它自己意识不到被操控了。

**为什么重要：** 教科书级的 Agent 信任边界失败。LangAlpha 漏洞可导致远程代码执行（CVSS 8.1）。随着 Agent 开始替人办事（下单、发邮件、操作服务器），间接提示注入的危害从"开玩笑"升级为"真金白银的损失"。

**常见误区：** 这不是传统的 SQL 注入或 XSS；防御方法也不同（需要输入 sanitization、权限最小化、人工确认关键操作）。
