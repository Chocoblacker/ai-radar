# MCP（模型上下文协议）

**是什么：** Anthropic 推出的开放标准，让 AI Agent 能以统一的方式连接外部工具、数据源和 API。可以理解为 Agent 世界的"USB 接口"——不管什么工具，只要支持 MCP，Agent 就能即插即用。

**为什么重要：** Agent 落地的互操作底座。Virtana 用 MCP 召集多个不同专长的 Agent 协同排障；Trust3 治理方案覆盖 MCP 服务器。随着 Agent 数量爆发，MCP 正在成为事实标准。

**常见误区：** MCP 不是模型本身，而是一个协议；它不解决 Agent 的安全问题（权限、审计需要额外的治理层）。

**相关故事线：** 🧵 agent-security

**英文表达：** Model Context Protocol, MCP
